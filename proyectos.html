Laboratorio Galatea

Sitio institucional para un laboratorio cosmético de Montevideo, con un blog que el propio cliente actualiza desde Notion.

Cliente
Laboratorio cosmético
Ubicación
Montevideo
Tipo
Sitio de una página + blog
Estado
En línea
Ver sitio en vivo →

Diseño

  • ✦Paleta crema, azul marino y dorado, pensada para transmitir confianza.
  • ✦Tipografías Fraunces para títulos e Inter para textos.
  • ✦Menú hamburguesa para navegar cómodo desde el celular.
  • ✦Línea de tiempo de seis pasos que explica el proceso del laboratorio.

Funciones

  • ✦Formulario de contacto conectado a Formspree: las consultas llegan directo al correo.
  • ✦Sitio publicado en GitHub Pages.
  • ✦Verificación en Google Search Console.
  • ✦Perfil de empresa en Google iniciado.

Blog autoeditable

  • ✦Comparé Decap CMS, Notion y WordPress, y elegí Notion por lo fácil que es para el cliente.
  • ✦El cliente escribe en una base de Notion con título, categoría, imagen de portada, resumen y autor.
  • ✦Un script en Node.js con GitHub Actions publica en el sitio las entradas marcadas como “Publicado”, cada 6 horas.
  • ✦Le dejé una guía paso a paso para que lo use solo.
